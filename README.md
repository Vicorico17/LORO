# Loro

Loro is a creator licensing dashboard for consent-led campaign work.

## Creator campaign picks

Creators can open the **Campaigns** view, review eligible opportunities, and pick the campaigns they want to participate in. Picking a campaign updates the card to **Selected**, increments the selection count, and shows a confirmation toast. A creator can remove a selection any time before the campaign starts.

## Run locally

This is a dependency-free static app. Open `index.html` in a browser or serve the folder with any static file server.

## Deploy

The app is configured for a static Vercel deployment. Run `vercel deploy . -y` from the project directory for a preview deployment.
